pnpm build

The pipeline, in dependency order

Two formats share one dist, so every step has to agree on the file layout. The order lives in scripts/build.mjs instead of a shell chain, and the last step refuses to finish quietly.

1 src/** Every publishable module is its own Rollup entry 63 components + lib + hooks
2 Vite mode=es Clears dist first; one file per module dist/**/*.js
3 Vite mode=cjs Adds to the first pass; skips the two ESM-only modules dist/**/*.cjs
4 tsc --emitDeclarationOnly One declaration per module, source maps included *.d.ts
5 fix-declarations Relative specifiers get the .js the runtime loads node16-safe .d.ts
6 dts Copies each declaration into the CommonJS context *.d.cts
7 copy-styles Publishes the whole stylesheet directory, adds @source dist/styles/*.css
8 check-build Parity · directive count · exports resolve · no stray output fails the build

The order lives in one file — and the last step knows every way this package has broken before.
