One package, two doors

The barrel only carries what resolves with the core dependencies. A component that needs a heavy library is reachable, but only through a deep import — so a bundler never looks for recharts because someone imported a button.

@konopskidev/ui

The root barrel. Resolves with the core dependencies alone.

react radix-ui cn class-variance-authority tailwindcss tw-animate-css
52 components — Button, Card, Dialog, …

@konopskidev/ui/components/<name>

The second door. Eleven components, each with the optional peer it needs. Installed on demand; absent peers stay absent.
